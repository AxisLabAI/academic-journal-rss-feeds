## 利用方法

研究者は一覧から学術誌を探し、状態を確認して RSS リーダーに URL を追加できます。誤りや利用できないリンクは Issue でお知らせください。

[OPML](dist/feeds.opml) には HTTP を含む未検証候補がすべて入っています。調査用の一括ファイルであり、動作確認済みの推奨購読セットではありません。必要なフィードを個別に確認してください。

開発者向け JSON：

```bash
curl -fL https://raw.githubusercontent.com/AxisLabAI/academic-journal-rss-feeds/main/data/feeds.json -o feeds.json
```

`name` で検索し、`feed_url` とともに `status`、`last_checked` を確認してください。出版社の利用条件、キャッシュ要件、レート制限を守り、サーバーから取得する際は公開ネットワーク宛先とリダイレクトを検査してください。全 URL への高並列アクセスは避けてください。

## データ仕様

| フィールド | 説明 |
| --- | --- |
| `id` | 正規化 URL の SHA-256 の先頭 16 桁。URL が変わると ID も変わります |
| `name` | 元データの誌名。表記の整理が必要な場合があります |
| `feed_url` | RSS・Atom・RDF の候補 URL。拡張子だけで形式を判断しません |
| `host` | URL のホスト名。出版社の確認済み識別子ではありません |
| `status` | 検証状態 |
| `last_checked` | UTC の確認日。null は現在の証拠がないことを意味します |
| `provenance` | データの出典区分 |

| 状態 | 意味 |
| --- | --- |
| `needs-review` | 発見・取り込み済み。誌名、形式、可用性の確認が必要 |
| `active` | 公式性、RSS/Atom/RDF 形式、1 件以上の項目を指定日に確認済み |
| `unavailable` | 確認した証拠に基づき、現在利用不可。回復する可能性があります |
| `deprecated` | 廃止または置き換えが確認されています |

HTTP 200 や過去の取得時刻だけでは検証になりません。初回公開には active レコードがなく、継続稼働を保証しません。

## 出典と安全性

初期データには、過去の ZiNote スナップショットから誌名と公開フィード URL のみを取り込みました。内部データベース ID、運用時刻、ユーザー情報、認証情報、インパクトファクター、論文本文、抄録は含みません。取り込み日と検証日は異なります。出版社からの推薦や提携を意味するものではありません。

## 保守と貢献

`data/feeds.json` が正本です。一覧、CSV、OPML、統計はスクリプトで生成します。英語版は README.md、中国語版は README.zh-CN.md です。

Node.js 20 以上が必要です。外部ランタイムパッケージは不要です。

```bash
npm run build
npm test
git diff --exit-code -- dist docs/CATALOG.md
```

CI はフィールド、URL 形式、重複、状態、自動生成物の再現性を確認します。オンラインの稼働確認ではありません。日本語・中国語・英語の Issue とプルリクエストを歓迎します。[貢献方法](CONTRIBUTING.md)を参照してください。

今後は公式性とフィード内容の検証、古い URL の修正、根拠のある ISSN・分野・出版社情報の追加を進め、20,000 誌を目指します。
